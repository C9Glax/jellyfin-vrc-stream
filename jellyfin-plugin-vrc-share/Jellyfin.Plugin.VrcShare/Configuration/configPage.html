VRC Share

Adds a "VR Share Link" button to item detail pages that mints a time-limited playback link from your jellyfin-vrc-stream proxy and copies it to the clipboard.

Base URL of your jellyfin-vrc-stream proxy, e.g. https://stream.example.com (should match PUBLIC_BASE_URL on the proxy).

Generates a Jellyfin API key and sends it to the proxy automatically - no need to create one by hand or paste it into two places. Save Proxy Base URL first. Use Re-pair to recover if the proxy's pairing was reset (e.g. after a restart with non-persistent storage) or to rotate the key.
Set automatically by Pair/Re-pair above. Only edit this by hand if you're pointing at a key created outside this plugin - it must match JELLYFIN_API_KEY (or the proxy's paired key) exactly. Used server-side only - never sent to the browser.
How long a share link stays valid by default (e.g. 86400 = 24 hours).
Turns off the request-time script injection if it ever conflicts with another plugin. The plugin's API endpoints keep working either way.
